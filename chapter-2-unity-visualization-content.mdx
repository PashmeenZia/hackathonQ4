# Chapter 2 — Unity for Human-Robot Interaction & Sensor Simulation

## Introduction

Unity is a powerful 3D development platform that excels at creating high-fidelity visualizations and interactive experiences. For robotics applications, Unity provides an ideal environment for visualizing robot sensors, creating immersive human-robot interaction scenarios, and developing intuitive interfaces for robot teleoperation. This chapter explores how to leverage Unity's capabilities for humanoid robot simulation, focusing on sensor visualization and human-robot interaction.

Unlike physics simulation in Gazebo, which emphasizes accurate physical behavior, Unity focuses on visual realism and user experience. This makes it perfect for creating intuitive interfaces that help humans understand what robots are perceiving and how they're interpreting their environment. For humanoid robots, Unity can visualize complex sensor data in ways that are easily interpretable by human operators.

The combination of Gazebo for physics simulation and Unity for visualization creates a comprehensive digital twin environment where robots can be tested for both physical feasibility and human interaction. This dual approach allows developers to validate not just how robots move and behave, but also how they appear and interact from a human perspective.

In this chapter, we'll cover the fundamentals of setting up Unity for robotics applications, implementing sensor visualization systems, and creating interactive environments that facilitate human-robot collaboration. By the end of this chapter, you'll be able to create Unity scenes that visualize robot sensors (LiDAR, cameras, IMUs) and allow basic interaction with simulated robots.

## Sensor Simulation in Unity

Unity can simulate various types of robotic sensors, providing visual feedback that helps users understand what the robot is perceiving. The most common sensors for humanoid robots include LiDAR, cameras, and IMUs, each with specific visualization techniques.

### LiDAR Simulation

LiDAR (Light Detection and Ranging) sensors emit laser pulses and measure the time it takes for the light to return after hitting objects. In Unity, we can simulate LiDAR using raycasting techniques:

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class LiDARSimulation : MonoBehaviour
{
    [Header("LiDAR Configuration")]
    public int numberOfRays = 360;
    public float maxRange = 10.0f;
    public float minRange = 0.1f;
    public float rotationSpeed = 10.0f;

    [Header("Visualization")]
    public GameObject pointCloudPrefab;
    public Material pointMaterial;

    private List<GameObject> pointCloudObjects;
    private LineRenderer lineRenderer;

    void Start()
    {
        InitializeLiDAR();
    }

    void Update()
    {
        SimulateLiDARScan();
    }

    void InitializeLiDAR()
    {
        pointCloudObjects = new List<GameObject>();

        // Create line renderer for visualization
        lineRenderer = gameObject.AddComponent<LineRenderer>();
        lineRenderer.material = pointMaterial;
        lineRenderer.widthMultiplier = 0.02f;
        lineRenderer.positionCount = numberOfRays;
    }

    void SimulateLiDARScan()
    {
        Vector3[] hitPoints = new Vector3[numberOfRays];

        for (int i = 0; i < numberOfRays; i++)
        {
            float angle = (i * 360.0f / numberOfRays) * Mathf.Deg2Rad;
            Vector3 direction = new Vector3(Mathf.Cos(angle), 0, Mathf.Sin(angle));

            RaycastHit hit;
            Vector3 rayStart = transform.position;
            Vector3 rayDirection = transform.TransformDirection(direction);

            if (Physics.Raycast(rayStart, rayDirection, out hit, maxRange))
            {
                if (hit.distance >= minRange)
                {
                    hitPoints[i] = hit.point;

                    // Optional: Create visual point for each hit
                    if (i % 10 == 0) // Only create every 10th point to reduce overhead
                    {
                        CreateLiDARPoint(hit.point);
                    }
                }
                else
                {
                    hitPoints[i] = rayStart + rayDirection * minRange;
                }
            }
            else
            {
                hitPoints[i] = rayStart + rayDirection * maxRange;
            }
        }

        lineRenderer.SetPositions(hitPoints);
    }

    void CreateLiDARPoint(Vector3 position)
    {
        GameObject point = GameObject.CreatePrimitive(PrimitiveType.Sphere);
        point.transform.position = position;
        point.transform.localScale = Vector3.one * 0.02f;
        point.GetComponent<Renderer>().material = pointMaterial;
        point.GetComponent<Collider>().enabled = false; // Disable collider to avoid physics interactions

        pointCloudObjects.Add(point);

        // Remove old points to prevent memory buildup
        if (pointCloudObjects.Count > 1000)
        {
            GameObject oldPoint = pointCloudObjects[0];
            pointCloudObjects.RemoveAt(0);
            Destroy(oldPoint);
        }
    }
}
```

This script creates a simulated LiDAR that performs raycasting in multiple directions and visualizes the returned points. The visualization shows both the ray paths and the points where objects were detected.

### Camera Simulation

Cameras are essential for visual perception in robotics. Unity can simulate both RGB cameras and depth cameras for humanoid robots:

```csharp
using UnityEngine;

public class CameraSimulation : MonoBehaviour
{
    [Header("Camera Configuration")]
    public Camera rgbCamera;
    public Camera depthCamera;

    [Header("Visualization")]
    public Material depthMaterial;
    public RenderTexture depthTexture;

    [Header("Parameters")]
    public float nearClip = 0.1f;
    public float farClip = 10.0f;

    void Start()
    {
        SetupCameras();
    }

    void SetupCameras()
    {
        // Configure RGB camera
        if (rgbCamera == null)
        {
            rgbCamera = GetComponent<Camera>();
        }

        // Create depth camera
        if (depthCamera == null)
        {
            GameObject depthCamObj = new GameObject("DepthCamera");
            depthCamObj.transform.SetParent(transform);
            depthCamObj.transform.localPosition = Vector3.zero;
            depthCamObj.transform.localRotation = Quaternion.identity;

            depthCamera = depthCamObj.AddComponent<Camera>();
            depthCamera.CopyFrom(rgbCamera); // Copy settings from RGB camera
        }

        // Create depth texture
        if (depthTexture == null)
        {
            depthTexture = new RenderTexture(640, 480, 24);
            depthTexture.format = RenderTextureFormat.Depth;
        }

        depthCamera.targetTexture = depthTexture;
        depthCamera.clearFlags = CameraClearFlags.SolidColor;
        depthCamera.backgroundColor = Color.white;
    }

    // Method to get depth data
    public float GetDepthAtScreenPoint(Vector2 screenPoint)
    {
        // Convert screen point to viewport coordinates
        Vector2 viewportPoint = new Vector2(screenPoint.x / Screen.width, screenPoint.y / Screen.height);

        // Sample depth texture
        RenderTexture.active = depthTexture;
        Texture2D depthSample = new Texture2D(1, 1);
        depthSample.ReadPixels(new Rect(viewportPoint.x * depthTexture.width,
                                       viewportPoint.y * depthTexture.height,
                                       1, 1), 0, 0);
        Color depthColor = depthSample.GetPixel(0, 0);
        DestroyImmediate(depthSample);
        RenderTexture.active = null;

        // Convert color to depth value
        float depthValue = depthColor.r;
        return depthValue * (farClip - nearClip) + nearClip;
    }
}
```

This camera simulation provides both RGB and depth data, which are crucial for humanoid robots that need to perceive their environment visually.

### IMU Simulation

IMUs (Inertial Measurement Units) provide orientation and acceleration data. In Unity, we can simulate IMUs by tracking the robot's movement and applying realistic noise:

```csharp
using UnityEngine;

public class IMUSimulation : MonoBehaviour
{
    [Header("IMU Configuration")]
    public float accelerometerNoise = 0.01f;
    public float gyroscopeNoise = 0.01f;
    public float magnetometerNoise = 0.1f;

    [Header("Visualization")]
    public TextMesh orientationDisplay;

    private Vector3 lastPosition;
    private Quaternion lastRotation;
    private Vector3 acceleration;
    private Vector3 angularVelocity;

    void Start()
    {
        lastPosition = transform.position;
        lastRotation = transform.rotation;
        acceleration = Vector3.zero;
        angularVelocity = Vector3.zero;
    }

    void Update()
    {
        SimulateIMU();
        UpdateVisualization();
    }

    void SimulateIMU()
    {
        // Calculate linear acceleration
        Vector3 velocity = (transform.position - lastPosition) / Time.deltaTime;
        Vector3 currentAcceleration = (velocity - acceleration) / Time.deltaTime;

        // Add gravity to acceleration (assuming Z is up)
        currentAcceleration += Physics.gravity;

        // Apply noise to acceleration
        currentAcceleration += Random.insideUnitSphere * accelerometerNoise;

        // Calculate angular velocity
        Quaternion deltaRotation = transform.rotation * Quaternion.Inverse(lastRotation);
        Vector3 deltaAngle = new Vector3(
            Mathf.Atan2(2 * (deltaRotation.x * deltaRotation.w + deltaRotation.y * deltaRotation.z),
                        1 - 2 * (deltaRotation.z * deltaRotation.z + deltaRotation.w * deltaRotation.w)),
            Mathf.Atan2(2 * (deltaRotation.y * deltaRotation.w - deltaRotation.z * deltaRotation.x),
                        1 - 2 * (deltaRotation.y * deltaRotation.y + deltaRotation.x * deltaRotation.x)),
            Mathf.Atan2(2 * (deltaRotation.z * deltaRotation.x + deltaRotation.y * deltaRotation.w),
                        1 - 2 * (deltaRotation.y * deltaRotation.y + deltaRotation.z * deltaRotation.z))
        );

        Vector3 currentAngularVelocity = deltaAngle / Time.deltaTime;

        // Apply noise to angular velocity
        currentAngularVelocity += Random.insideUnitSphere * gyroscopeNoise;

        // Store values
        acceleration = currentAcceleration;
        angularVelocity = currentAngularVelocity;
        lastPosition = transform.position;
        lastRotation = transform.rotation;
    }

    void UpdateVisualization()
    {
        if (orientationDisplay != null)
        {
            Vector3 eulerAngles = transform.rotation.eulerAngles;
            orientationDisplay.text = $"Orientation: {eulerAngles.x:F2}, {eulerAngles.y:F2}, {eulerAngles.z:F2}\n" +
                                    $"Accel: {acceleration.x:F3}, {acceleration.y:F3}, {acceleration.z:F3}\n" +
                                    $"AngVel: {angularVelocity.x:F3}, {angularVelocity.y:F3}, {angularVelocity.z:F3}";
        }
    }

    // Public methods to access IMU data
    public Vector3 GetLinearAcceleration()
    {
        return acceleration;
    }

    public Vector3 GetAngularVelocity()
    {
        return angularVelocity;
    }

    public Quaternion GetOrientation()
    {
        return transform.rotation;
    }
}
```

This IMU simulation provides realistic orientation and acceleration data with appropriate noise levels, making it suitable for humanoid robot applications.

using UnityEngine;

public class EnvironmentSetup : MonoBehaviour
{
    [Header("Environment Configuration")]
    public GameObject[] obstacles;
    public Material[] environmentMaterials;

    [Header("Interactive Elements")]
    public GameObject[] interactiveObjects;
    public Material highlightMaterial;

    void Start()
    {
        SetupEnvironment();
        ConfigureInteractions();
    }

    void SetupEnvironment()
    {
        // Create a simple room environment
        CreateRoom();

        // Add obstacles
        PlaceObstacles();

        // Apply materials
        ApplyEnvironmentMaterials();
    }

    void CreateRoom()
    {
        // Create floor
        GameObject floor = GameObject.CreatePrimitive(PrimitiveType.Plane);
        floor.transform.SetParent(transform);
        floor.transform.localScale = Vector3.one * 10;
        floor.name = "Floor";

        // Create walls
        CreateWalls();
    }

    void CreateWalls()
    {
        // Create four walls
        for (int i = 0; i < 4; i++)
        {
            GameObject wall = GameObject.CreatePrimitive(PrimitiveType.Cube);
            wall.transform.SetParent(transform);

            // Position walls to form a room
            float angle = i * 90 * Mathf.Deg2Rad;
            float distance = 10f / 2f;
            wall.transform.position = new Vector3(
                Mathf.Cos(angle) * distance,
                2.5f,
                Mathf.Sin(angle) * distance
            );

            // Rotate walls appropriately
            wall.transform.rotation = Quaternion.Euler(0, angle, 0);
            wall.transform.localScale = new Vector3(0.2f, 5f, 10f);
            wall.name = $"Wall_{i}";

            // Make walls static for better performance
            wall.GetComponent<Collider>().isTrigger = false;
        }
    }

    void PlaceObstacles()
    {
        // Randomly place obstacles in the environment
        for (int i = 0; i < obstacles.Length; i++)
        {
            GameObject obstacle = Instantiate(obstacles[i]);
            obstacle.transform.SetParent(transform);

            // Random position within the room
            Vector3 position = new Vector3(
                Random.Range(-4f, 4f),
                0.5f,
                Random.Range(-4f, 4f)
            );
            obstacle.transform.position = position;

            // Random rotation
            obstacle.transform.rotation = Quaternion.Euler(0, Random.Range(0, 360), 0);
        }
    }

    void ApplyEnvironmentMaterials()
    {
        // Apply materials to environment objects
        Renderer[] renderers = GetComponentsInChildren<Renderer>();
        foreach (Renderer renderer in renderers)
        {
            if (environmentMaterials.Length > 0)
            {
                renderer.material = environmentMaterials[Random.Range(0, environmentMaterials.Length)];
            }
        }
    }

        {
            // Add interaction components
            if (obj.GetComponent<Collider>() != null)
            {
                // Add outline or highlight effect for interactive objects
                SetupInteractiveVisuals(obj);
            }
        }
    }

    void SetupInteractiveVisuals(GameObject obj)
    {

    }
}

## Visualization Techniques for Sensor Data

Effective visualization of sensor data is crucial for understanding robot perception. Unity provides several techniques for visualizing different types of sensor data:

### LiDAR Point Cloud Visualization

Create an optimized system for visualizing large point clouds:

```csharp
using UnityEngine;
using System.Collections.Generic;

public class PointCloudVisualizer : MonoBehaviour
{
    [Header("Point Cloud Configuration")]
    public Material pointMaterial;
    public float pointSize = 0.02f;
    public int maxPoints = 10000;

    [Header("Performance")]
    public bool useGPUInstancing = true;

    private List<Vector3> points;
    private GameObject[] pointObjects;
    private int pointCount = 0;

    void Start()
    {
        points = new List<Vector3>();
        pointObjects = new GameObject[maxPoints];
    }

    public void AddPoint(Vector3 point)
    {
        if (pointCount >= maxPoints)
        {
            // Remove oldest point
            if (pointObjects[pointCount % maxPoints] != null)
            {
                DestroyImmediate(pointObjects[pointCount % maxPoints]);
            }

            // Add new point
            points[pointCount % maxPoints] = point;
            pointObjects[pointCount % maxPoints] = CreatePointObject(point);
        }
        else
        {
            points.Add(point);
            pointObjects[pointCount] = CreatePointObject(point);
        }

        pointCount++;
    }

    GameObject CreatePointObject(Vector3 position)
    {
        GameObject point = GameObject.CreatePrimitive(PrimitiveType.Sphere);
        point.transform.position = position;
        point.transform.localScale = Vector3.one * pointSize;

        Renderer renderer = point.GetComponent<Renderer>();
        renderer.material = pointMaterial;

        if (useGPUInstancing && pointMaterial.enableInstancing)
        {
            renderer.material.enableInstancing = true;
        }

        // Disable physics for visualization points
        DestroyImmediate(point.GetComponent<Collider>());

        return point;
    }

    public void ClearPoints()
    {
        for (int i = 0; i < pointObjects.Length; i++)
        {
            if (pointObjects[i] != null)
            {
                DestroyImmediate(pointObjects[i]);
                pointObjects[i] = null;
            }
        }

        points.Clear();
        pointCount = 0;
    }

    // Method to update with new point cloud data
    public void UpdatePointCloud(List<Vector3> newPoints)
    {
        ClearPoints();

        foreach (Vector3 point in newPoints)
        {
            AddPoint(point);
        }
    }
}
```

## Performance Optimization for Lightweight Simulation

Since the specification requires free-tier friendly and lightweight workflows, it's important to optimize Unity simulations:

### Level of Detail (LOD) Systems
```csharp
using UnityEngine;

public class RobotLODSystem : MonoBehaviour
{
    [Header("LOD Configuration")]
    public float[] lodDistances = { 10f, 20f, 50f };
    public GameObject[] lodModels;

    private Camera mainCamera;

    void Start()
    {
        mainCamera = Camera.main;
        SetupLODModels();
    }

    void Update()
    {
        UpdateLOD();
    }

    void SetupLODModels()
    {
        // Ensure we have the correct number of LOD models
        for (int i = 0; i < lodModels.Length; i++)
        {
            if (lodModels[i] != null)
            {
                lodModels[i].SetActive(i == 0); // Only first LOD active initially
            }
        }
    }

    void UpdateLOD()
    {
        if (mainCamera == null) return;

        float distance = Vector3.Distance(mainCamera.transform.position, transform.position);

        for (int i = 0; i < lodDistances.Length; i++)
        {
            if (distance <= lodDistances[i])
            {
                ActivateLOD(i);
                return;
            }
        }

        // If beyond all distances, activate the lowest detail LOD
        ActivateLOD(lodDistances.Length);
    }

    void ActivateLOD(int lodIndex)
    {
        for (int i = 0; i < lodModels.Length; i++)
        {
            if (lodModels[i] != null)
            {
                lodModels[i].SetActive(i == lodIndex);
            }
        }
    }
}
```

## Troubleshooting Common Unity Simulation Issues

### Performance Problems
- **Reduce polygon count**: Simplify models, especially for distant objects
- **Optimize lighting**: Use baked lighting instead of real-time where possible
- **Limit sensor visualization**: Don't render every sensor point if not necessary
- **Use object pooling**: Reuse objects instead of constantly creating/destroying them

### Sensor Accuracy Issues
- **Calibrate simulation parameters**: Ensure simulated sensors match real-world specifications
- **Add appropriate noise**: Real sensors have noise; include this in simulation
